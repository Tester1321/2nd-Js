# Show Message (JS Mini Project)

## Description

This is a simple JavaScript-based Show Message. It shows a message in the box below the submit button. The project also includes a light/dark mode toggle and Arabic/English toggle for better user experience.

## Features

- Displays the entered message below.
- Light/Dark mode toggle.
- Arabic/English toggle
- Built with Bootstrap and scss for styling.

## How to Run

Clone the repository:

```bash
git clone https://github.com/Tester1321/2nd-Js.git
```
